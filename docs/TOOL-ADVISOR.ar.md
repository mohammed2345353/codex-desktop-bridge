# مستشار الأدوات — مساعد يرشدك وأوامر تختصر الخطوات

إصدار 0.3.0 يضيف المستشار إلى مشروع Codex Desktop Bridge بدون إلغاء المخطط
السابق. تسأل المهارة عن المهمة؛ تشرح شنو تستخدم، شنو ناقص، وأي أمر تشغّل.
ما تنزّل أو تفتح أو تنفّذ المهمة تلقائياً من مجرد النصيحة.

من داخل مجلد المشروع، في PowerShell:

```powershell
.\Tools.ps1 -Action Catalog
.\Tools.ps1 -Action Inventory | Select-Object skillFiles,scope
.\Tools.ps1 -Action Search -Query 'موشن' | Select-Object name,description,path
.\Tools.ps1 -Action Recommend -Task 'إنشاء مهارة' -BudgetUsd 0
.\Tools.ps1 -Action Profile
.\Tools.ps1 -Action Export
```

الأوامر الخمسة الأولى تفحص أو تعرض أو تنصح، بدون حفظ ملفات أو فتح برامج.
Export يحفظ جرداً قابلاً للبحث داخل `.bridge/advisor`. يحتوي مسارات جهازك؛
لا تنشره على GitHub. تگدر تحدد الجذور بـ `-Roots` ومجلد الحفظ بـ `-StateDirectory`.

الموجود على القرص مو بالضرورة مثبت أو محمّل بهالمحادثة. أسماء إعدادات MCP
مو دليل اتصال. الكلفة المجهولة تبقى مجهولة، ووجود Plus أو Pro ما يثبت رصيد API.
النصوص المعقدة في وصف المهارة تحتاج فحص إضافي. الروابط الرمزية وjunctions تُتجاوز.

بعد ما تتأكد أنت من وصولك للميزة وكلفتها ومكان المعالجة، مثال فقط:

```powershell
.\Tools.ps1 -Action Confirm -ToolId codex -Access subscription -Processing external -FeatureCostUsd 0 -PlanLabel 'اشتراكي المؤكد' -Ready
.\Tools.ps1 -Action Recommend -Task 'إنشاء مهارة' -BudgetUsd 0
```

التأكيد محلي ومن المستخدم، مو اختبار خدمة حي. ينتهي افتراضياً بعد 12 ساعة.
تأكيد الاشتراك ما يثبت الحصة الباقية. لا تدخل بريد أو مفتاح أو كلمة مرور.
حذف `-Ready` يسجل أن الطريق غير جاهز. إذا الكلفة مجهولة لا تدخل صفر بدلها.

الترشيح المحلي يعتمد كلمات مفتاحية وكتالوج صغير، مو فهم ذكي لكل طلب. دور
المساعد يفهم الطلب ويفحص الأدوات المناسبة ويشرح الخطوة التالية. الكلفة
والجاهزية المجهولتان ما تصيران ترشيحاً رئيسياً. تأكيدات المخطط القديم منفصلة
وأكثر تحديداً لحصة المهام؛ بيانات المستشار ما تخصص أعمال عليه تلقائياً.

فتح برنامج خطوة مستقلة يختارها المستخدم:

```powershell
.\Tools.ps1 -Action Open -ToolId vscode -WhatIf
.\Tools.ps1 -Action Open -ToolId vscode
```

الأول معاينة، والثاني يطلب فتح المسار المعروف فقط. ما يرسل المهمة ولا يفتح
ملفاتك. المسارات الحالية تدعم أماكن VS Code الشائعة وأدوبي 2026/2027؛ مكان
آخر قد يحتاج تعديل كتالوج بعد المراجعة. لا تنزيل تلقائي ولا أوامر مأخوذة من نص المهمة.

لتثبيت المهارتين داخل مشروع تختاره:

```powershell
.\scripts\Install-Skills.ps1 -Workspace 'C:\MyProject' -WhatIf
.\scripts\Install-Skills.ps1 -Workspace 'C:\MyProject'
```

إذا نسخة موجودة مختلفة، راجعها واستخدم `-Replace` ليحفظ نسخة احتياطية قبل
التحديث. ابدأ محادثة Codex جديدة لتحديث اكتشاف المهارات. ما تتغير إعدادات
MCP أو المهارات العامة. الأوامر تحتاج PowerShell 5.1 أو 7؛ ما تحتاج Python
أو API أو اشتراك جديد. تعليمات المستشار نفسها تبقى قابلة للاستخدام بدون المشروع.

الأوامر المحلية ما تستدعي نموذج AI. لكن طلب تنفيذها أو تحليل النتائج عبر
Codex ممكن يستهلك من استخدامه. الخدمات والتوليد تبقى إلها حدودها وكلفتها؛
ماكو تجاوز للحصص أو وعد بنسبة توفير. أي تنزيل مقترح من المساعد لازم يوضح
الحاجة والمصدر والكلفة أولاً.
