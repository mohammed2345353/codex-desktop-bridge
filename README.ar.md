# Codex Desktop Bridge — منظّم شغلك على أدوات AI

[English](README.md) · الإصدار **0.2.0** · Windows · ملفات محلية · ترخيص MIT

هذا صار المشروع الأساسي بنفس المستودع القديم: يكتشف دليل وجود أدواتك، يخليك تأكّد وصولك وحدودك، ويجهّز طلباً حسب هدفك تسلّمه إلى AI تختاره. بعد مراجعة الخطوات اللي يرجعها، يحوّلها إلى **Flowchart مرقّم وتفاعلي**. كل خطوة توضح الأداة المقترحة والتعليمات والمتطلبات؛ إنت تعلّم «كملت» بعد مراجعة النتيجة حتى تبين الخطوة الجاهزة بعدها.

## شغّله

1. من GitHub اختار **Code → Download ZIP** وفك الضغط.
2. إذا عندك PowerShell 7، افتح **Start.cmd**، أو شغّل:

   ```powershell
   .\scripts\Start-Workflow.ps1
   ```

3. من القائمة: اكتشاف الأدوات ← تأكيد وصولك ← كتابة هدفك وتجهيز طلب للـAI ← مراجعة ملف خطواته ← إنشاء المخطط. تگدر تبدأ بالمثال بدون حسابات.

المشغّل ما ينزّل برامج ولا يغيّر سياسة تشغيل السكربتات. إذا سياسة جهازك تمنع التشغيل، يوضّح الخطأ. السكربتات تدعم PowerShell 5.1 و7 إذا سياسة الجهاز تسمح. بعض الاختيارات مثل yes وlocal وsubscription مكتوبة بالقائمة حتى تدخلها كما هي.

## شنو يسوي؟

- يفحص أسماء محدّدة بالمسارات وسجل Windows بدون تشغيل البرامج: Codex وClaude وGemini وAntigravity وVS Code وأدوات Adobe وOllama.
- إنت تأكّد نوع الوصول والقدرات والنموذج والمعالجة المحلية أو الخارجية والكلفة والحدود؛ بدون كلمات مرور.
- يجهّز طلباً حسب غرضك، حتى الـAI ينصحك بالأداة أو النموذج أو الموقع المناسب، والسبب والبديل والمخرجات. تراجع الطلب وتسلّمه بنفسك.
- يوزّع الخطوات حسب القدرة والخصوصية والكلفة والحدود المؤكّدة. المهمة الخاصة تبقى للمعالجة المحلية، والمتطلبات المعطلة تمنع ما يعتمد عليها.
- ينتج HTML واحد بدون إنترنت: مخطط وتفاصيل مرقّمة، حفظ واسترجاع التقدّم، وتراجع يلغي إكمال الخطوات التابعة. من زر الطباعة تگدر تحفظ PDF ثابتاً.
- يستخدم Graphlib وأيقونة Google محلياً، مع تراخيصها وبصمات التحقق؛ ما يحتاج CDN أو تثبيت إضافات عامة.

## وين ملفاتك؟

داخل `.bridge/workflow/`، المستثنى من Git. التقارير والطلبات والمخططات إلها أسماء جديدة حتى ما تنمسح ملفات سابقة. قبل تحديث تأكيدات الحساب، يسألك عن الحفظ ويحتفظ بنسخة سابقة. التأكيد من القائمة صالح 12 ساعة، وبعدها يحتاج تحديث. الميزانية الإضافية الافتراضية صفر.

```powershell
.\scripts\Start-Workflow.ps1 -Action Discover
.\scripts\Start-Workflow.ps1 -Action Prepare -Goal 'أريد أسوي ريل تعليمي'
.\scripts\Start-Workflow.ps1 -Action Configure
.\scripts\Start-Workflow.ps1 -Action Plan -TasksPath 'C:\MyTasks\reviewed.json'
.\scripts\Start-Workflow.ps1 -Action Demo
```

## الحدود الواضحة

وجود البرنامج مو إثبات أصالته أو تسجيل الدخول أو الاشتراك أو جاهزية النموذج. الويب والنسخ المحمولة ممكن تحتاج تأكيداً يدوياً. الكلفة والحدود تقديرات منك؛ مو قراءة حية لحسابك. تقسيم الطلب الحر والنصائح تحصل عليها عبر تسليم طلب للـAI اللي تختاره؛ ماكو خدمة AI سحابية مضمّنة تتصل تلقائياً.

المشروع ما يرسل بيانات ولا يشغّل برامج الطرف الثالث ولا يقرأ جلسات المتصفح ولا يصوّر الشاشة. تگدر تختار لقطة شاشة وتخفي معلوماتها الخاصة وتشاركها بنفسك؛ أي فحص شاشة أو إضافات إضافي يحتاج نطاق قراءة وموافقة منفصلة. راجع الطلب المصدّر قبل مشاركته لأنه يتضمن هدفك وخريطة التأكيدات.
