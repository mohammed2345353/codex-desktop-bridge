# مخطط العمل المحلي — نسخة أولية

المشروع يرتّب شغلك على الأدوات اللي تختارها. PowerShell يفحص دليل وجود البرامج، والـAI اللي إنت تختاره يقدر يقترح تفصيل المهمة ونصائح لكل مرحلة. المخطط المحلي يراجع الشروط ويعرض التسلسل. ما ينفّذ المهام بنفسه.

## نقطة البدء الموحّدة

افتح `Start.cmd` إذا عندك PowerShell 7، أو شغّل `scripts/Start-Workflow.ps1`. القائمة تقودك عبر اكتشاف الأدوات، تأكيد وصولك، تجهيز طلب حسب هدفك، وتحويل خطوات JSON اللي راجعتها إلى مخطط. كل شيء يُحفظ محلياً داخل `.bridge/workflow/`. ما تنفتح ملفات أو برامج تلقائياً. التأكيد من القائمة ينتهي بعد 12 ساعة ويحتاج موافقتك قبل الحفظ، مع نسخة احتياطية للإعدادات السابقة. أسماء المخرجات فريدة حتى ما تنكتب فوق ملفات قديمة. السكربت ما يغيّر سياسة PowerShell ولا يثبّت مكونات.

## ابدأ بالمثال

```powershell
.\examples\Show-DemoWorkflow.ps1 | Set-Content -LiteralPath demo.html -Encoding UTF8
```

افتح الملف من جهازك: أربع مراحل لكتابة ريل ومراجعته وتجهيز الرسم وترتيب الفيديو. أسماء الحسابات عليها DEMO؛ كلها محاكاة وما تثبت حساباتك الحقيقية. زر «كملت» تأكيد شخصي بعد مراجعتك للنتيجة. التقدّم بالذاكرة فقط؛ نزّل حالته حتى تسترجعه لاحقاً. الرجوع عن خطوة يلغي إكمال الخطوات التابعة إلها. زر الطباعة يفتح حوار المتصفح؛ تقدر تختار Save as PDF. PDF ثابت، وHTML تفاعلي.

## اكتشاف الأدوات

```powershell
.\scripts\Get-AIToolMap.ps1 -AsJson
```

القراءة تشمل أسماء العرض من مفاتيح Uninstall للحساب الحالي والجهاز، بنسختي 32 و64 بت، وفحص أسماء ملفات محددة على PATH. النتيجة تشمل الأدوات المعروفة في الكتالوج فقط، ولا تكشف قائمة برامجك الكاملة أو المسارات. عدم العثور على أداة مو دليل عدم وجودها: أدوات Microsoft Store والنسخ المحمولة والويب قد لا تنكشف. يظهر تحذير إذا تعذرت بعض القراءات. تشابه اسم البرنامج دليل محتمل، مو إثبات أصالة الملف.

ما نستعمل Win32_Product، ولا نستدعي --version، ولا نفتح التطبيقات. ما نقرأ حسابات أو مفاتيح API أو سجل متصفح أو ملفات المشاريع أو محتوى الشاشة. ما نغيّر إعدادات الجهاز أو سياسة PowerShell. الاكتشاف وحده لا يتصل حتى بـOllama المحلي.

## تأكيد حساباتك

انسخ `examples/confirmations.example.json` إلى مكان محلي مثل `.bridge/accounts.json`؛ المجلد مستثنى من Git. كل الأدوات تبدأ غير مفعلة. لا تكتب كلمات مرور أو بريد حسابك أو رموز وصول. لكل أداة:

| الحقل | معناه |
| --- | --- |
| `id` | المعرّف الموجود بالكتالوج |
| `available` | `true` فقط إذا أكّدت بنفسك أنك تقدر تستخدم الأداة |
| `access` | `local-free` أو `free` أو `subscription` أو `paid-api`؛ غير المعروف يُستبعد |
| `processing` | `local` أو `external`؛ برنامج على جهازك ممكن يرسل للسحابة |
| `capabilities` | القدرات اللي أكّدتها من القائمة المعلنة للأداة |
| `modelLabel` | اختياري: اسم النموذج اللي أكّدت وصولك إله؛ ما نستنتجه من اسم البرنامج |
| `confirmedAt` | وقت التأكيد ISO 8601 مع المنطقة الزمنية |
| `validUntil` | انتهاء التأكيد؛ أقصى مدة 24 ساعة، وبعدها يُستبعد حتى تحديثه |
| `incrementalCostUsd` | تقديرك للكلفة الإضافية لكل مهمة بالدولار؛ صفر إذا ضمن وصولك الحالي |
| `remainingTasks` | عدد الأجزاء اللي تسمح بتخصيصها بهذه الخطة؛ عدد صحيح، مو قراءة حية للرصيد |

خانة `paid-api` توثّق إمكانية فقط؛ ما تضيف اتصال API. الميزانية الافتراضية صفر. اشتراك ChatGPT أو Claude مو دليل رصيد API. وجود Ollama ما يثبت وجود نموذج محلي منزّل، ووجود VS Code ما يثبت وجود إضافة AI. Adobe يتطلب تأكيد الميزة الفعلية والرصيد المناسب لها. الكتالوج ما يثبّت أسعاراً أو حصصاً رقمية تتغير بين الحسابات.

## تفصيل المهمة والنصائح

ابدأ بهدفك، وحدد المدخلات والنتيجة اللي تريدها. حمّل «تعليمات للـAI» من المثال أو خطتك، **راجع الملف قبل مشاركته** لأنه يحتوي نص المهمة وخريطة التأكيدات، ثم سلّمه بنفسك إلى AI تختاره. اطلب منه يشرح لكل خطوة:

1. الأداة أو الموقع أو التطبيق المناسب، والنموذج إذا تعرف وصولك الفعلي إله.
2. سبب الاختيار حسب غرضك، البديل، والمدخلات المطلوبة.
3. ناتج محدد تسلّمه للخطوة التالية، ونقطة مراجعة قبل التنفيذ.

المخطط يقترح أدوات حسب نوع المرحلة، مو اختبار جودة يقارن النماذج، وما يخترع اسم نموذج أو اشتراك. ضع النصائح والمخرجات المتوقعة داخل `instruction`. الـAI يرجع JSON مثل `examples/tasks.json`. راجعه محلياً قبل استخدامه. النسخة الحالية ما تفكك طلباً حراً تلقائياً وما تستدعي نموذجاً؛ تقبل تفصيلاً منك أو من الـAI اللي اخترته.

يمكنك إرفاق لقطة شاشة تختارها بعد إخفاء المعلومات الخاصة. إذا أردت أن يستخدم الـAI الشاشة أو يفحص إضافات محرر: حدّد الجهاز والمجلد والأوامر ووافق على قراءة محددة عبر أداة مناسبة. هذا ليس تصريحاً بفحص شامل. أمر الاكتشاف والمخطط لا ينفذان هالفحص، ولا يتجاوزان صلاحيات أي أداة.

كل عنصر مهام يحتوي `id`, `title`, `capability`, `privacy`, `dependsOn`, `instruction`. القدرات: `writing`, `coding`, `review`, `image`, `video`. الخصوصية `private` للمعالجة المحلية فقط، أو `public` للمحتوى اللي يجوز تسليمه خارجياً بعد مراجعتك. `dependsOn` قائمة معرفات خطوات سابقة؛ لا دورات أو مراجع مستقبلية. حد الإدخال 1 MiB و100 مهمة. النص بيانات حرفية ولا يُفسَّر كأمر.

```powershell
.\scripts\New-AIWorkflow.ps1 -TasksPath .\my-tasks.json -ConfirmationsPath .\.bridge\accounts.json -Format Html |
    Set-Content -LiteralPath workflow.html -Encoding UTF8
# JSON كامل، يتضمن أسباب استبعاد كل أداة:
.\scripts\New-AIWorkflow.ps1 -TasksPath .\my-tasks.json -ConfirmationsPath .\.bridge\accounts.json
```

الأوامر ترجع نصاً فقط. الحفظ يحدث لأنك تختار `Set-Content`. استخدم أسماء ملفات جديدة حتى تحافظ على عملك السابق، وخزّن التقارير والخطط محلياً؛ ممكن تحتوي تعليماتك الخاصة. لا ترفعها للمستودع.

## طريقة التوزيع وحدودها

نستبعد التأكيد المفقود/القديم، القدرة غير المؤكدة، الكلفة والرصيد المجهولين، والمهام الخاصة لأي معالجة خارجية. نوزع بالتسلسل: أقل كلفة إضافية، ثم المحلي، ثم الأقل تخصيصاً بين الخيارات المتساوية. ما نفرض عدة أدوات إذا أداة واحدة أنسب. نخصم الحصص والميزانية افتراضياً داخل الخطة فقط. لا حجز فعلي، لا تحديث رصيد حساب، ولا ضمان أن النص الطويل يساوي طلباً واحداً. الخوارزمية بسيطة وجشعة؛ ترتيب المهام قد يؤثر على النتيجة ولا تحسّن الخطة كلها رياضياً. تعطل متطلب سابق يبقي ما يعتمد عليه معطلاً.

HTML ملف واحد بمكتبة المخطط وأيقونته وتراخيصهما. لا CDN أو تحليلات أو خادم، ولا إرسال أو تحميل تلقائي. النص يدخل الواجهة بواسطة `textContent`، وبيانات الخطة مضمّنة بترميز آمن. روابط المصادر لا تُفتح إلا بنقرتك. تصدير تعليمات AI وحالة التقدم تنزيل محلي باختيارك؛ ما يكتب الحافظة. التأكيدات ممكن تنتهي بعد إنشاء الملف: راجع الحساب قبل التسليم الفعلي أو أنشئ خطة جديدة؛ الصفحة ليست فحصاً حياً.
